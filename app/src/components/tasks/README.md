# AgriTech Task Recommendation System

The Task Recommendation system allows farmers to get AI-powered task recommendations for each of their crops. This README explains how to use this system effectively.

## Features

1. **Access All Crops**: Navigate to the Tasks section from the main menu to see all your registered crops.
2. **Crop-Specific Tasks**: Select any crop to view, manage, and generate tasks for that specific crop.
3. **AI-Powered Recommendations**: Generate personalized task recommendations using Gemini AI based on:
   - Crop type and variety
   - Growth stage
   - Previous activities
   - Weather conditions
   - Seasonal factors
4. **Task Management**: Mark tasks as complete, skip them, or filter by category.
5. **Task History**: View completed tasks for performance tracking and analysis.

## How to Use

### Accessing Tasks for Different Crops
1. Click on the "Tasks" menu item in the navigation bar
2. You'll see a grid of all your registered crops
3. Click on any crop card to view and manage tasks for that specific crop
4. Navigate between crops using the arrows in the Task Dashboard

### Generating AI Recommendations
1. Open the tasks for a specific crop
2. Click the "Generate Recommendations" button
3. Wait while the AI analyzes your crop data and generates personalized tasks
4. Review the recommended tasks in the modal that appears
5. Select which recommendations you want to add to your task list
6. Click "Save Selected" to add them to your tasks

### Managing Tasks
- Toggle between "Today," "Upcoming," and "History" tabs to view different tasks
- Use the category filter to focus on specific types of tasks
- Mark tasks as completed using the checkmark button
- Skip tasks that aren't relevant using the skip button

## Troubleshooting

If you encounter any issues:
1. Make sure you're logged in with a valid account
2. Check your internet connection
3. Verify that crop data is correctly entered
4. For API errors, try refreshing the page or generating recommendations again

## Tips for Better Recommendations

- Keep crop details up to date, especially planting date and growth stage
- Record all activities performed for accurate context
- Use the system regularly to improve AI understanding of your farming practices
